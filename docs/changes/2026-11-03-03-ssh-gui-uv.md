- `tests/ssh-gui/ssh_server.py`：保留 Paramiko 环回服务、随机合成凭据、真实主机密钥和三种服务模式；增加正常退出及 SIGTERM 凭据清理、避免覆盖既有凭据、状态 JSON 原子写入。

- 使用已安装 uv 创建本地 `.venv` 并同步依赖，缓存限定到项目 `.uv-cache`；不修改全局 Python 环境。
- 新增 `docs/validation/ssh-gui-testing.md`，更新项目说明、索引和 Native 测试复现命令；旧临时脚本的验证事实保留为历史记录。
