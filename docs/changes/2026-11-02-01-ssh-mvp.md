# 实现第一阶段 SSH 登录 MVP

- 日期：2026-11-02（Asia/Shanghai）
- 执行者：Codex（本会话，依据实际操作补录）
- 关联：首版实现，纳入本次代码交付

## 需求与目的

在 DevEco Native C++ 模板上完成最小 SSH 连接闭环，包括主机身份核对、密码认证、状态、取消和断开；阶段范围不包含终端及文件传输。

## 具体操作

- `entry/src/main/ets/pages/Index.ets`：替换 Hello World 为连接表单、状态提示、指纹确认和断开交互。
- `entry/src/main/cpp/ssh_client.{h,cpp}`：新增后台连接线程、非阻塞 TCP/SSH、SHA256 指纹、密码认证、超时、取消和资源清理。
- `napi_init.cpp` 与 `types/libentry/Index.d.ts`：定义连接、认证、状态和断开的桥接契约与输入校验。
- `entry/src/main/ets/entryability/EntryAbility.ets`：退出或切后台断开。
- `entry/src/main/module.json5`：声明 INTERNET 权限；更新应用显示名称。
- `entry/build-profile.json5` 与 CMake：使用 C++17，限定已有依赖支持的 ARM64。
- `entry/libs/`、`third_party/`：引入本地参考项目的 libssh2/libcrypto 静态库、头文件与许可证及来源记录。
- `tests/native/`：添加 loopback SSH 集成测试；设备测试添加 Native 输入契约检查。
- 按用户后续要求，将完整实现同步至用户指定的桌面工程，在该目录继续开发并重新构建。

## 验证

- OHPM 依赖同步、Hvigor `assembleHap` 成功，输出未签名 HAP，包含 ARM64 Native 库。
- 本机以官方 libssh2 1.11.1 + OpenSSL 3 构建同一连接核心，运行 `tests/native/integration.py`，6 个真实 SSH 场景通过。
- 具体环境、命令和验收清单见 [验证记录](../validation/mvp-validation.md)。

## 限制与风险

本机测试不代表打包 ARM64 静态库的设备验证。预编译 OpenSSL 依赖的确切构建来源与补丁尚未完全核实；正式发布前需要替换为可复现且受支持的构建并完成安全审核。仅支持 IP 字面地址，不支持域名、终端或文件传输。
