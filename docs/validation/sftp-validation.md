# SFTP 单文件传输验证

## 本机集成测试

按 [MVP 验证](mvp-validation.md) 构建本机 libssh2 1.11.1 与测试程序，按 [uv 环境说明](ssh-gui-testing.md) 安装测试依赖。执行：

```sh
.venv/bin/python tests/native/integration.py /absolute/path/to/ssh_client_test
```

测试在本机环回地址运行临时 Paramiko 服务，使用合成凭据和临时目录。除既有 6 个 SSH 场景外，SFTP 场景覆盖中文及空格文件名、二进制逐字节比对、空文件、同名目标保护、远端文件不存在、远端拒绝写入、取消上传和下载、取消后在同一会话继续上传。另校验旧连接编号、相对路径、并发请求被拒绝，上传任务在调用方关闭原始 fd 后仍能完成。服务端检查已取消的上传未生成目标，且取消与失败后无远端临时文件。

## 设备验收

用 [双 ABI 构建说明](native-dependencies.md) 生成 HAP，安装至 HarmonyOS 模拟器或真机。准备设备可达、已启用 `sftp` 子系统的 OpenSSH 测试实例和可读写目录，使用合成账号。先从可信渠道取得服务器指纹。

- [ ] 在连接前从系统 Picker 选择本地文件，再确认指纹并登录。填写包含文件名的远端绝对路径，上传后在服务器校验 SHA-256。
- [ ] 下载刚上传的文件，观察进度，完成后通过系统 Picker 保存。比对导出文件与原文件的 SHA-256。
- [ ] 分别验证空文件、中文或空格文件名、大文件、取消 Picker 和导出失败后重试。
- [ ] 验证同名上传不会覆盖原文件，以及远端缺少文件、无权限、未启用 SFTP 时的提示。
- [ ] 传输中取消，检查远端临时文件和本地缓存，随后在同一连接重试。再验证中途断网、切后台和主动断开后的状态、缓存处理与重连。
- [ ] 确认系统 Picker 对应用生命周期的影响。若返回后 SSH 已断开，确认可用已选文件重新登录，或继续导出已下载的缓存。

进度以传输字节计。上传在服务器确认改名后完成，下载在完整接收并写入应用缓存后才开放导出。导出失败可能在选定位置留下部分文件，完整缓存可用于重试。远端断线可能导致临时文件残留，或使最终改名结果无法确认，界面会在检测到该情况时提示。

## 2026-11-04 模拟器实测

DevEco Studio 在 Mate 90 Pro ARM64 模拟器（HarmonyOS 7.0 / API 26）构建、安装并启动了 `feature/sftp-single-file`。用户在应用内完成指纹确认及登录，通过 Mac OpenSSH 下载 47 字节的样本，使用系统 Picker 保存到 Downloads，再选择该文件上传到 Mac。Mac 原文件、模拟器导出的文件和带 `renew` 后缀的回传文件 SHA-256 一致。真机及上述异常场景仍待验收。详见 [实测记录](../changes/2026-11-04-04-sftp-emulator-round-trip.md)。

## 远程文件管理

本机集成测试覆盖从登录目录进入子目录、根目录与父目录导航、目录和文件属性、无权限与不存在的路径、创建和重命名目录、删除空目录和拒绝删除非空目录。测试还在同一连接中上传文件，从列表找到它，验证同名重命名失败，再按新名称下载并逐字节比对，最后删除文件。测试服务校验原文件及符号链接未被改动。

设备端验收仍需在模拟器或真机完成。

- [ ] 登录后确认初始路径，依次验证打开文件夹、上一级、直接跳转、刷新和空目录。
- [ ] 从列表下载文件、通过 Picker 保存并核对哈希。选本地文件后上传到当前目录，确认列表自动出现新文件。
- [ ] 新建、重命名并删除空目录。尝试删除非空目录，确认其中的文件仍在。验证文件重命名、同名冲突、删除确认和取消。
- [ ] 操作中断开连接再重连，确认列表重新加载，并用刷新核对中断时的远端结果。
