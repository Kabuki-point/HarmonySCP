# SSH 终端与 Phone 验证

## 本机测试

按 [原生测试命令](mvp-validation.md#复现本机集成测试) 编译测试程序，再运行 `tests/native/integration.py`。新增 `terminal` 场景使用 Paramiko 环回服务和合成账号，服务端回显字节，不执行命令。检查认证前和过期连接编号的请求拒绝、PTY 拒绝后可重试、中文输入回显、尺寸变更、EOF 前输出完整交付、主动关闭、同连接切回 SFTP，以及连接断开时关闭 PTY。设备端 Hypium 另有 NAPI 状态和输出类型的基本契约检查。

## Phone 验收清单

待在 ARM64 / API 24 和 API 26 的 Phone 上用签名 HAP 验收。可用 x86_64 模拟器跑功能回归。

- [ ] 核对指纹并登录，打开终端。检查远端提示符、ANSI 颜色和中文输出。
- [ ] 用系统输入法组字并分别点击发送按钮、输入法回车。检查组字期间未发送，提交后仅发送一次，软键盘出现时仍能看到光标。
- [ ] 用功能键栏测试 Ctrl+C、Tab、Esc 和方向键。接入外接键盘检查长按、组合键、草稿内光标移动，以及回车只提交一次。
- [ ] 长按选择并复制，点击系统粘贴按钮。检查授权失败时无输入发送，授权成功时处理纯文本及 bracketed paste。
- [ ] 旋转屏幕、双指缩放、收起键盘后，检查 `stty size` 与当前视口一致，运行中的全屏程序能正常重绘。
- [ ] 传输过程中尝试打开终端，确认入口提示稍后重试。正常退出 shell 或从终端返回后，确认仍在原文件目录并可使用 SFTP。
- [ ] 测试切后台、远端断线、连续开关终端和重连。检查 UI 提示和资源释放。
